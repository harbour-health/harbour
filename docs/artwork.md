# Artwork

## What it is

Harbour's four original vector illustrations add colour and depth to health records and the conversation screen. They use hand-drawn paths and solid shapes rather than symbol fonts or downloaded imagery.

## How it works

`HarbourIllustration` draws into a SwiftUI `Canvas` using a 240 × 200 coordinate system. It scales and centres the artwork inside the supplied frame. Readings use a cobalt torus and ochre pulse; medicines use angled two-tone capsules; symptoms use a bound notebook and perforated bandage; conversation uses Harbour's four-part mark with orbiting speech bubbles.

Solid offset edges, highlights, and small shadows create depth. The pale support shapes adapt to the current colour scheme. The illustration is decorative, hidden from accessibility, and ignores taps so the containing control owns its label and interaction.

Today's shortcuts deliberately offset their 195 × 163-point illustrations beyond the bottom/right edge and clip them to the tile's rounded boundary. A contrasting circular arrow occupies the opposite corner. Change placement in `TodayView.illustratedShortcut`, not the drawing coordinates, so full illustrations in chat and empty states remain intact.

```swift
HarbourIllustration(kind: .medicines)
    .frame(width: 150, height: 125)

HarbourIllustration(kind: .conversation, animated: true)
    .frame(height: 190)
```

## How to change it

Edit `Harbour/Illustrations.swift`. Each illustration has its own drawing method in `IllustrationBoard`; helpers draw shared capsules, speech bubbles, sparkles, strokes, and rounded forms. Keep the composition within the 240 × 200 drawing area and check both small feature thumbnails and larger empty states. Parents can clip the drawing when using a partial illustration at the edge of a screen.

To add artwork, add a case to `IllustrationKind`, a matching switch branch, and a drawing method. Update the Xcode project after adding this source file if its source list has not already been regenerated by the normal project workflow.

## Configuration

`kind` selects `.readings`, `.medicines`, `.symptoms`, or `.conversation`. `animated` defaults to `false`; only conversation supports a gentle three-point vertical float. The system Reduce Motion setting disables that animation. Repeating animations stop when their view disappears, including the waiting mark, so switching chats does not retain an invisible animation. Keep dashboard thumbnails static. Colours are local constants in `IllustrationBoard`; there are no environment variables, gradient assets, or remote asset requests.

## Dependencies

SwiftUI provides `Canvas`, `GraphicsContext`, and `Path`. The artwork has no third-party dependencies. Its shapes are original source artwork; it does not include imagery copied from another app.
